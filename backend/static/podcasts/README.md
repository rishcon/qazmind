# Папка для аудио-подкастов

## Структура файлов

Загружайте аудио файлы в эту папку в формате MP3.

### Рекомендации по названиям:
- Используйте латиницу и цифры
- Без пробелов (используйте подчеркивание или дефис)
- Примеры:
  - `ablai_khan_5min.mp3`
  - `golden_horde_history.mp3`
  - `kz_independence_3min.mp3`

### После загрузки файлов:
Добавьте информацию о подкастах в базу данных через админ панель или напрямую в базу.
