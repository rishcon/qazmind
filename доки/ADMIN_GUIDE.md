## Форматы загрузки вопросов

### 1. JSON формат (рекомендуется)

Массив объектов с вопросами:

```json
[
  {
    "subject_id": 1,
    "text_kz": "Текст вопроса на казахском",
    "text_ru": "Текст вопроса на русском",
    "options_kz": [
      "Вариант 1",
      "Вариант 2",
      "Вариант 3",
      "Вариант 4"
    ],
    "options_ru": [
      "Вариант 1",
      "Вариант 2",
      "Вариант 3",
      "Вариант 4"
    ],
    "correct_answer_index": 1,
    "fact_snippet_kz": "Объяснение на казахском для AI",
    "fact_snippet_ru": "Объяснение на русском для AI",
    "difficulty": "medium",
    "topic": "Название темы"
  }
]
```

**Поля:**
- `subject_id` (обязательно) - ID предмета (1 = История Казахстана)
- `text_kz` (обязательно) - Текст вопроса на казахском
- `text_ru` (обязательно) - Текст вопроса на русском
- `options_kz` (обязательно) - Массив из 4 вариантов ответа на казахском
- `options_ru` (обязательно) - Массив из 4 вариантов ответа на русском
- `correct_answer_index` (обязательно) - Индекс правильного ответа (0-3)
- `fact_snippet_kz` (опционально) - Факты для AI-объяснений на казахском
- `fact_snippet_ru` (опционально) - Факты для AI-объяснений на русском
- `difficulty` (опционально) - Сложность: "easy", "medium", "hard" (по умолчанию "medium")
- `topic` (опционально) - Тема вопроса

---

### 2. CSV формат

**Заголовок:**
```
subject_id,text_kz,text_ru,options_kz,options_ru,correct_answer_index,fact_snippet_kz,fact_snippet_ru,difficulty,topic
```

**Пример строки:**
```
1,Қазақстан тәуелсіздігін қашан алды?,Когда Казахстан получил независимость?,1990 жылы|1991 жылы|1992 жылы|1993 жылы,В 1990 году|В 1991 году|В 1992 году|В 1993 году,1,Қазақстан 1991 жылы тәуелсіздік алды,Казахстан получил независимость в 1991 году,easy,Тәуелсіздік
```

**Важно:**
- Варианты ответов разделяются символом `|` (вертикальная черта)
- Всегда должно быть ровно 4 варианта
- Индекс правильного ответа: 0, 1, 2 или 3

## Как загрузить вопросы

### Через JSON:
1. Войдите как администратор
2. Перейдите на вкладку "JSON"
3. Вставьте JSON-код в текстовое поле
4. Нажмите "Отправить"

### Через CSV:
1. Войдите как администратор
2. Перейдите на вкладку "CSV"
3. Выберите CSV файл
4. Нажмите "Загрузить"

## Рекомендации

### Для качественных AI-объяснений:

1. **fact_snippet** должен содержать:
   - Конкретные даты, имена, события
   - Краткое, но полное объяснение
   - Только достоверные факты

2. **Плохой пример:**
   ```
   "fact_snippet_ru": "Это важное событие"
   ```

3. **Хороший пример:**
   ```
   "fact_snippet_ru": "Казахстан получил независимость 16 декабря 1991 года после распада СССР. Это ключевая дата в истории современного Казахстана."
   ```

### Для difficulty:
- `easy` - Базовые даты, простые факты
- `medium` - Требует понимания контекста
- `hard` - Сложные связи, глубокие знания

## API Endpoints (для разработчиков)

```
GET  /api/admin/subjects          - Список предметов
GET  /api/admin/questions/stats   - Статистика вопросов
POST /api/admin/questions/bulk    - Массовая загрузка (JSON)
POST /api/admin/questions/import-csv - Импорт из CSV
DELETE /api/admin/questions/{id}  - Удаление вопроса
```

## Устранение проблем

### "Subject ID not found"
- Проверьте, что subject_id = 1 (История Казахстана)

### "Must have exactly 4 options"
- Убедитесь, что каждый вопрос имеет ровно 4 варианта ответа
- В CSV варианты разделены символом `|`

### "correct_answer_index must be 0-3"
- Индекс начинается с 0
- Для 4 вариантов: 0, 1, 2 или 3
