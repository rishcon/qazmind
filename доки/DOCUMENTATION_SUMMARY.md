## 🚀 Команды для быстрого старта

```bash
# Клонирование
git clone https://github.com/qazmind/qazmind.git
cd qazmind

# Backend
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python init_db.py
uvicorn main:app --reload

# В другом терминале - Frontend
cd frontend
npm install
npm run dev

# Откройте в браузере
open http://localhost:5173
```
