# 🎴 Флеш-карточки с алгоритмом Spaced Repetition

## ✨ Что это?

Система флеш-карточек для эффективного запоминания материала с использованием алгоритма **SuperMemo-2** (Spaced Repetition).

### Особенности:

- 🃏 **Tinder-стиль**: Свайп влево/вправо или кнопки
- 🔄 **Переворот карточки**: Нажмите на карточку, чтобы увидеть ответ
- 🧠 **Умное повторение**: Карточки показываются в оптимальное время
- 📊 **Прогресс**: Отслеживание изученных карточек
- 🎨 **Красивый UI**: Анимации с framer-motion

## 🎮 Как использовать

### 1. Механика свайпов:

- **Свайп вправо** или кнопка "Знаю" → Карточка появится через 3+ дня
- **Свайп влево** или кнопка "Учу" → Карточка появится через 10 минут

### 2. Алгоритм SuperMemo-2:

Система автоматически рассчитывает интервалы повторения:

- **Первое повторение**: 1 день
- **Второе повторение**: 6 дней
- **Дальше**: интервал × коэффициент легкости (EF)

### 3. Коэффициент легкости (EF):

- Начальное значение: **2.5**
- "Знаю" → EF увеличивается
- "Учу" → EF уменьшается, карточка сбрасывается

### 4. Статус "Освоено":

Карточка считается освоенной когда:
- EF > 3.0 (легко дается)
- Интервал > 30 дней

## 📡 API Endpoints

### GET `/api/flashcards/due/{subject_id}`
Получить карточки для повторения (максимум 20)

**Пример:**
```bash
curl http://localhost:8000/api/flashcards/due/1 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### POST `/api/flashcards/review`
Отправить результат повторения

**Body:**
```json
{
  "card_id": 1,
  "quality": 4
}
```

**Quality шкала:**
- 0 - Полное незнание
- 1 - Неправильно (Учу)
- 2 - Неправильно, но было знакомо
- 3 - Правильно с трудом
- 4 - Правильно легко (Знаю)
- 5 - Идеально

**Ответ:**
```json
{
  "next_review": "2024-01-20T10:30:00",
  "interval_days": 3
}
```

### GET `/api/flashcards/stats`
Получить статистику

**Ответ:**
```json
{
  "today": 5,      // Карточек на сегодня
  "total": 58,     // Всего карточек с прогрессом
  "mastered": 12   // Освоенных карточек
}
```

### POST `/api/flashcards/admin/create` (Admin only)
Создать новую карточку

**Body:**
```json
{
  "subject_id": 1,
  "front": "1465 год",
  "back": "Образование Казахского ханства",
  "hint": "Керей и Жанибек"
}
```

## 🗄️ База данных

### Таблица `flashcards`

| Поле | Тип | Описание |
|------|-----|----------|
| id | Integer | ID карточки |
| subject_id | Integer | ID предмета |
| front | Text | Вопрос/лицевая сторона |
| back | Text | Ответ/обратная сторона |
| hint | Text | Подсказка (опционально) |
| created_at | DateTime | Дата создания |

### Таблица `flashcard_reviews`

| Поле | Тип | Описание |
|------|-----|----------|
| id | Integer | ID записи |
| user_id | Integer | ID пользователя |
| flashcard_id | Integer | ID карточки |
| easiness_factor | Float | Коэффициент легкости (2.5) |
| interval | Integer | Интервал в днях |
| repetitions | Integer | Количество повторений |
| last_review | DateTime | Последнее повторение |
| next_review | DateTime | Следующее повторение |
| is_mastered | Boolean | Освоено ли |

## 🎯 Рекомендации по обучению

1. **Ежедневная практика**: Лучше 10 минут каждый день, чем час раз в неделю
2. **Честность**: Оценивайте себя честно (Знаю/Учу)
3. **Регулярность**: Проверяйте карточки каждый день
4. **Не спешите**: Прочитайте вопрос, подумайте, потом переворачивайте
5. **Используйте подсказки**: Если совсем не помните - смотрите hint

## 📈 Научный подход

Алгоритм SuperMemo-2 основан на исследованиях памяти:

- **Кривая забывания** (Ebbinghaus): Информация забывается экспоненциально
- **Оптимальные интервалы**: Повторение в момент начала забывания укрепляет память
- **Индивидуальная адаптация**: EF адаптируется под каждого пользователя

### Формула EF:
```
EF' = EF + (0.1 - (5-q) * (0.08 + (5-q) * 0.02))
```

Где:
- EF - текущий коэффициент
- q - качество ответа (0-5)
- EF' - новый коэффициент (минимум 1.3)
