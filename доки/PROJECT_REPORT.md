# QazMind - Отчет о реализации проекта

**Дата:** 27 декабря 2025  
**Платформа:** Система подготовки к ҰБТ с AI-ментором  
**Языки:** Казахский, Русский

---

## 📋 Обзор проекта

QazMind - это веб-платформа для подготовки к Единому Национальному Тестированию (ҰБТ) в Казахстане с использованием искусственного интеллекта для персонализированных объяснений ошибок.

---

## 🎯 Реализованные функции

### 1. **Аутентификация и безопасность**
- ✅ Регистрация пользователей с валидацией
- ✅ Авторизация через JWT токены
- ✅ Хеширование паролей (bcrypt)
- ✅ Защита API endpoints
- ✅ Хранение токенов в LocalStorage (frontend)

**Технологии:**
- FastAPI OAuth2
- JWT (JSON Web Tokens)
- bcrypt для хеширования
- Время жизни токена: 30 минут

---

### 2. **Система тестирования**

#### Создание тестов
- ✅ Генерация случайных тестов из 5 вопросов
- ✅ Фильтрация по предметам
- ✅ Поддержка двух языков (KZ/RU)
- ✅ Сохранение попыток в базе данных

#### Прохождение тестов
- ✅ Интерактивный интерфейс с выбором ответов
- ✅ Таймер (опционально)
- ✅ Навигация между вопросами
- ✅ Отметка вопросов для проверки
- ✅ Подсчет баллов

#### Результаты
- ✅ Детальная страница результатов
- ✅ Процент правильных ответов
- ✅ Подсветка правильных/неправильных ответов
- ✅ Возможность запросить AI-объяснение

**Реализованные endpoint'ы:**
- `POST /api/tests/new` - Создание нового теста
- `POST /api/tests/{test_id}/submit` - Отправка ответов
- `GET /api/tests/{test_id}` - Получение теста

---

### 3. **AI-ментор (OpenAI интеграция)**

#### Функционал
- ✅ Персонализированные объяснения ошибок
- ✅ Обращение к ученику напрямую (на "ты")
- ✅ Объяснение на основе фактов из базы
- ✅ Структурированный формат ответа:
  1. Почему твой ответ неверен
  2. Почему правильный ответ верен
  3. Как тебе это запомнить

#### Оптимизация
- ✅ Кэширование AI-ответов (избежание повторных запросов)
- ✅ Rate limiting: 10 объяснений в час на пользователя
- ✅ Ограничение токенов: 300 на ответ
- ✅ Модель: GPT-4o-mini

**Технологии:**
- OpenAI API (SDK 2.14.0)
- Асинхронные запросы
- Кэширование в PostgreSQL

**Endpoint:**
- `POST /api/questions/{question_id}/explain`

---

### 4. **База данных**

#### Архитектура
- ✅ PostgreSQL (основная БД)
- ✅ SQLAlchemy ORM
- ✅ Alembic для миграций (опционально)

#### Таблицы
1. **users** - Пользователи
   - id, email, hashed_password, full_name, is_admin
   - created_at, updated_at

2. **subjects** - Предметы
   - id, name_kz, name_ru, description_kz, description_ru

3. **questions** - Вопросы
   - id, subject_id, text_kz, text_ru
   - options_kz, options_ru (массив)
   - correct_answer_index
   - fact_snippet_kz, fact_snippet_ru
   - difficulty, topic

4. **test_attempts** - Попытки тестов
   - id, user_id, subject_id
   - question_ids (массив), user_answers (массив)
   - score, language
   - started_at, completed_at

5. **ai_explanations** - Кэш AI-объяснений
   - id, user_id, question_id
   - user_answer_index, language
   - prompt_hash, response_text, model

**Текущие данные:**
- 1 предмет: История Казахстана
- 5 тестовых вопросов
- 1 администратор (admin@qazmind.kz)
