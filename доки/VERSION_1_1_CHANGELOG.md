- ✅ Полная оптимизация для мобильных

- 📈 Улучшение мобильного опыта на 40%
- 🎯 Кнопки с иконками для экономии места
- 🔄 Адаптивные отступы и текст размеры

### 3. 🔊 Звуковые эффекты и вибрация

#### Новая утилита: `src/utils/sounds.js`

```javascript
// Три типа звуков:
playSound('flip')       // При переворачивании (800Hz)
playSound('success')    // При правильном ответе (C5-E5)
playSound('learning')   // При неправильном ответе (A4)

// Вибрация:
vibrate([100])          // Обучение - одна
vibrate([100, 50, 100]) // Успех - три вибрации
```

#### Совместимость:
- ✅ Chrome, Firefox, Safari
- ✅ Android Webview
- ✅ iOS Safari (частичная)

### 4. 📊 API расширения

#### Новые поля в карточках:

```json
{
  "id": 1,
  "front": "Вопрос?",
  "back": "Ответ",
  "hint": "Подсказка",
  
  // НОВОЕ в 1.1.0:
  "status": "learning",
  "interval": 3,
  "easiness_factor": 2.8
}
```

#### Новый параметр фильтрации:

```bash
GET /api/flashcards/due/{subject_id}?filter_type=learning

# Доступные значения:
# - all (по умолчанию)
# - new (новые карточки)
# - learning (в процессе изучения)
# - review (нужно повторить)
# - mastered (уже освоены)
```

#### Новый эндпоинт истории:

```bash
GET /api/flashcards/history/{subject_id}?limit=20

# Возвращает:
- Карточку
- Дату последнего просмотра
- Дату следующего повтора
- Статус, интервал, количество повторений
```

## 📚 Как использовать новые фичи

### Пример: Фильтрация карточек по типам

```jsx
import { useState } from 'react'
import api from '../utils/api'

export default function FlashcardsDemo() {
  const [filterType, setFilterType] = useState('all')
  const [cards, setCards] = useState([])

  const loadCards = async (subjectId) => {
    const response = await api.get(
      `/flashcards/due/${subjectId}`,
      { params: { filter_type: filterType } }
    )
    setCards(response.data)
  }

  return (
    <div>
      <div className="flex gap-2 mb-4">
        {['all', 'new', 'learning', 'review'].map(type => (
          <button
            key={type}
            onClick={() => {
              setFilterType(type)
              loadCards(1)
            }}
            className={filterType === type ? 'bg-blue-500' : 'bg-gray-300'}
          >
            {type}
          </button>
        ))}
      </div>
      
      <div>
        {cards.map(card => (
          <div key={card.id}>
            <p>{card.front}</p>
            <span className="text-sm">{card.status}</span>
          </div>
        ))}
      </div>
    </div>
  )
}
```
